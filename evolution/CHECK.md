# 检查协议（Check）

本文件约束 **检查 agent**。与进化 agent **分次运行、不共享对话记忆**；只通过仓库文件交接。

检查 agent **只读** 正式 `skill.md` 与待检提案；**通过前不得**把 diff 写入 `skill.md`。通过后才合并。

## 1. 触发与输入

- 当存在 `evolution/live_proposals/PENDING` 时运行（Automation 可每小时错峰扫描）。  
- 读取：`PENDING` 指向的 `gen_NNNN.md` + `gen_NNNN.diff`、当前正式 `skill.md`、本协议、`EVOLVE.md`（只读）。  
- 行情：stock-sdk MCP；点位时间规则同交易 skill。

## 2. 验收优先级

### P0 — 防穿越与合法性（否决）

- 提案是否为合法结构代（增/删/换因子，非纯调参）  
- 是否触及冻结区或放宽准冻结  
- 是否引入消息面  
- diff 是否可干净应用于当前 `skill.md`  
- 抽查：合并后规则是否仍要求 end_date≤T、T+1 成交、无未来函数  

任一失败 → **不合并**，记失败。

### P1 — 复核进化侧回撤声明

- 可信度检查：提案声称的 2023–2025 最大回撤灯号是否与其叙述一致；若 Check 有能力复跑 2023–2025，以复跑为准。  
- 红灯级回撤 → 否决。

### P2 — 2026 毕业考（进化不可见本段数字）

对 **拟合并后的规则**（在内存/临时副本应用 diff，勿先写正式文件）做 **2026 每个交易日** 点位时间纸交易回放：

记账：T→T+1 开盘；万三；ETF 无印花税；滑点 0.1%；起始 100 万。

**硬门槛（必须全部满足）：**

1. **已实现 YTD 净收益 ≥ 30%**（回放到「运行日上一交易日」或数据截止日；绿/黄灯相同）  
2. **2026 年 4 月**：月净收益 > 0；组合月收益 − 沪深300 月收益 ≥ **−3pct**；月内最大回撤 ≤ **12%**  
3. **2026 年 7 月**：同上三条（7 月截至数据截止日）

**软目标（不挡合并，必须写入报告）：**

- 已实现 YTD 是否 ≥ **70%**（标注「软达标 / 软未达」）

**预测：**

- **不作**年底收益外推或点预测。报告写明：「全年未完，不作收益预测。」仅报告已实现 YTD。

**真实可赚性反思（本 Check 的「反思」）：**

- 规则在真实环境是否可执行（流动性、T+1、成本假设）  
- 是否存在隐蔽穿越或过拟合 2023–2025 的迹象  
- 失败时给出 **失败类型枚举**（供下轮进化，尽量少泄露可刷分细节）：如 `LOOKAHEAD` / `PARAM_ONLY` / `DRAWDOWN` / `YTD_BELOW_30` / `APRIL_FAIL` / `JULY_FAIL` / `DIFF_INVALID` / `UNIVERSE`

## 3. 合并规则

| 结果 | 动作 |
|------|------|
| 全部硬门槛通过 | 将 diff **自动合并**进 `skill.md`；更新 §7 世代号；归档；删除 `PENDING`；连败计数归零 |
| 任一项失败 | **不合并**；写 audit；删除或清空 `PENDING`；连败 +1 |
| 连败达到 **3** | 另写 `evolution/log/PAUSED`（内容含原因与时间）；停止有效进化直至人工删除 |

黄灯提案与绿灯同一套 P2（YTD≥30%）；无额外 80% 要求。

## 4. 产出路径

| 文件 | 内容 |
|------|------|
| `evolution/audit/gen_NNNN_check.md` | P0/P1/P2 结果、已实现 YTD、4/7 月明细、软 70% 标记、可赚性反思、失败类型、是否合并 |
| `evolution/log/leaderboard.md` | 追加一行：世代、通过否、灯号、2023–2025 摘要（可抄提案）、2026 YTD（仅 Check 写）、时间 |
| `evolution/log/fail_streak` | 单行整数连败次数 |
| `evolution/log/PAUSED` | 仅连败≥3 时创建 |

合并后可将提案移至 `evolution/live_proposals/archive/gen_NNNN.*`（可选）。

## 5. Automation 行为摘要

触发：每小时（建议相对 Evolve 错峰，例如过 15 分），或等价「发现 PENDING 则跑」。  
动作：独立上下文验收 → 通过则改 `skill.md` 并提交；失败则归档原因。  
**禁止**修改 `EVOLVE.md` / `CHECK.md` 除非人工要求。
