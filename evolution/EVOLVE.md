# 进化协议（Evolve）

本文件约束 **进化 agent**。交易规则正文在仓库根目录 `skill.md`。验收见 `CHECK.md`。

## 1. 目标优先级

1. **P0**：防穿越；本协议与 CHECK 合规  
2. **P1**：2023–2025 walk-forward 组合最大回撤约束  
3. **P2**：由 Check 独占（本 agent **禁止**读取 2026 回测成绩或 Check 报告中的收益数字来决定是否提案）  
4. **P3**：相对上一代，在 2023–2025 上「更强」为软目标（结构升级后分数可略降，但须过 P1）

## 2. 数据与防穿越

- 行情来源（按可用性尝试）：Automations 已配置的行情 MCP，候选名包括 `stock-sdk` / `stock-sdk-mcp` / `china-a-stock-mcp` / `mcp-eastmoney` 等；以编辑器里实际可调用者为准。  
- 任意信号日 T：查询 **end_date ≤ T**，仅用 T 日 09:00 前可见字段。  
- 回看最多 **252** 个交易日。  
- **禁止**把 2026 年任意交易日的回测盈亏、4/7 月专项结果、YTD、是否 ≥30%/70% 写入适应度或「是否提交提案」的决策依据。  
- 适应度窗口：**2023-01-01～2025-12-31** 逐日点位时间回放（T→T+1 开盘，成本见 `skill.md` §0.3）。

### 2.1 行情 MCP 全不可用时的降级（允许出提案）

若本轮尝试后 **所有** 候选行情 MCP 均不可用（无法拉 K 线/资金流完成回放）：

1. **仍可**提交合法结构代提案（增/删/换因子），不得假装已回测。  
2. 提案灯号必须写 **`未回测`**；2023–2025 收益/回撤字段写 `N/A`，并列出已尝试且失败的 MCP 名称。  
3. **不得**编造绿/黄/红灯或虚构净值曲线。  
4. P1 定量验收 **顺延给 Check 独立复跑**；本 agent 只做结构合法性与反思。  
5. P3 软单调在本轮不适用（无适应度数字可比）。

## 3. 合法一代（结构闸）

每小时至多推进 **一代**。合法一代必须至少一项为真：

1. **新增** ≥1 个因子/规则（基本面 / 技术面 / 资金面），或  
2. **删除** ≥1 个无效/冗余因子/规则，或  
3. **替换** 某因子定义（输入或逻辑结构变化，而非单纯改阈值）

**非法（不算一代，不写待检提案，不触发合并路径）：**

- 纯参数代（只改止损%、仓位步长、均线周期等阈值）  
- 改冻结区（`skill.md` §0.0）或放宽准冻结硬顶/流动性  
- 引入消息面/新闻下单  
- 想不出结构变更却硬改文件  

无结构变更 → 输出 **「本小时跳过」**，更新 `evolution/log/skip_YYYYMMDD_HH.md` 一行原因即可。

## 4. P1 回撤灯号（适应度侧）

在 2023–2025 全程组合净值上（仅当行情 MCP 可用并完成回放时）：

| 最大回撤 | 灯号 | 动作 |
|----------|------|------|
| ≤ 20% | 绿 | 可写待检提案 |
| 20%–25% | 黄 | 可写待检提案，须在提案标明黄灯 |
| > 25% | 红 | **否决**，不写待检提案 |
| 未完成回放 | **未回测** | 可写待检提案；P1 交 Check 复跑 |

主分数：期间净收益；辅：收益/回撤。P3 软单调比较主分数与风险调整后表现（`未回测` 世代跳过 P3 比较）。

## 5. 反思强制段（每代提案必有）

提案必须回答：

- 本代是 **增 / 删 / 换** 哪一因子？属基本面、技术面还是资金面？  
- 针对上一代何种失效模式？  
- 对 2023–2025 哪类行情可能有害？  
- 为何不是调参能解决的问题？

## 6. 产出路径

设当代号为 `NNNN`（零填 4 位，读 `evolution/log/leaderboard.md` 最大世代 +1；若无则从 `0001`）：

| 文件 | 内容 |
|------|------|
| `evolution/live_proposals/gen_NNNN.md` | 完整提案：反思、变更说明、触及章节、2023–2025 摘要指标（收益、最大回撤、灯号）、**拟合并进 skill.md 的补丁说明** |
| `evolution/live_proposals/gen_NNNN.diff` | 对 `skill.md` 的 unified diff（或等价全文替换块） |
| `evolution/live_proposals/PENDING` | 单行：`gen_NNNN`（存在即表示等待 Check；Check 结束后删除或改写） |

**禁止**进化 agent 直接修改正式 `skill.md`（合并仅 Check 通过后执行）。  
**禁止**读取或修改 `evolution/audit/*` 中带 2026 成绩的报告来指导本代设计（可读取「失败类型标签」若 CHECK 仅提供枚举且无数字——默认连 audit 收益数字也不读；只读 `PENDING` 是否为空、leaderboard 的世代号与「通过/失败」布尔）。

## 7. 与 Check / 暂停

- 若 `evolution/live_proposals/PENDING` 已存在：本小时 **跳过**（上代未检完）。  
- 若 `evolution/log/PAUSED` 存在：跳过，直到人工删除该文件。  
- 连败 3 代由 Check 写入 `PAUSED`；进化不得自行清除。

## 8. Automation 行为摘要

触发：每小时。  
动作：读 `skill.md` + 本协议 → 结构反思 → 尝试 2023–2025 回放（MCP 全挂则标 `未回测`）→ 合法则写提案与 `PENDING`；否则跳过。  
不合并、不跑 2026。
